# Bartın Korsan Taksi

Bartın korsan taksi yaz aylarında Amasra'ya giden yolcuyla dolar. Çaycuma Havalimanı Bartın merkezden 36 kilometre, 30 dakika uzaklıktadır; Amasra'dan çıkan için 53 kilometre, 45 dakikadır. Hafta sonu sahil yolunda trafik olduğundan dönüş saati erken tutulur.

Amasra'nın kale içi sokaklarına araç giremediğinden yolcu surların dışında bırakılır. İnkumu plajı merkeze yakındır. Ahşap tekne yapımıyla bilinen Kurucaşile 89 kilometre, 1 saat 20 dakikalık yoldur; Ulus ise iç kesimde kalır.
